# Project Instructions

- Keep raw Alice EEG files outside this repository.
- Store only small derived tables, scripts, figures, and documentation here.
- Do not commit private data, raw EEG files, `.env` files, or large generated
  outputs.
- Prefer subject-level tables with one row per participant for this analysis.
- Treat comprehension score proportion as the primary behavioral outcome:
  `score_prop = correct / total`.
- Document any exclusion choice, especially S21, S39, high-noise subjects, and
  subjects with `/4` scores.
